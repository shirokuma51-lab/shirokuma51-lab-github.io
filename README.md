# 猫の神経衰弱

OBSでカードをめくり、同じ種類の猫が揃うと猫が落ちて積み上がる配信ツールです。

## ページ

- `display.html`：OBSのブラウザソース用。幅1536・高さ2048。開始・リセット・カードはOBSの「対話」から操作します。
- `index.html`：従来のURLでも同じ配信表示が開きます。
- `admin.html`：スマホ・PC向け管理画面。登録済みの管理者メールアドレスとパスワードでログインします。
- `viewer.html`：旧スロット参加機能の終了案内です。

## 管理画面の使い方

1. 背景と音量は操作すると配信表示へすぐ反映されます。
2. カードのペア数、裏面、猫の種類、絵柄、効果音を編集して「カード・効果音を保存」を押します。
3. カードの変更は、配信表示の「開始」を押すと反映されます。リセットはカードだけを片付けます。落ちた猫はページを再読み込みするまで残ります。
4. 猫の種類を開くと、落下画像とカードの絵柄を別々に選べます。同じ種類なら違う絵柄でも正解です。
5. 絵柄の「出やすさ」は相対値です。1と3なら約25%と75%、0なら出ません。カード1枚ずつ抽選します。猫の種類には均等にペアを割り当て、余りはランダムに割り当てます。

## 画像と音声

管理画面の画像保管庫へファイル選択・ドラッグ＆ドロップで画像を追加できます。PNG・JPEG・WebP、入力15MB以下、保存50枚まで。長辺512px以下のWebPへ圧縮し、Base64文字列が350,000文字以内になるよう必要に応じてさらに縮小します。透過は維持します。アニメーション画像の動きは保存しません。

画像はFirestoreの `memoryImages/slot0`〜`slot49` に1枚ずつ保存します。Cloud Storageや有料プランは使用しません。画像の細部は圧縮で変化するため、大きな素材・高画質素材・音声はチャットで受け取りGitHubの `assets/` に追加する運用です。標準画像は削除できません。使用中の保存画像は、設定で別の画像へ変更・保存してから削除してください。

無料枠の保存量・読込回数・転送量には上限があります。OBSは使用画像をページ内で再利用します。画像保管庫は管理画面を開いたときに読み込みます。課金設定は変更しません。

## ファイル構成

```
assets/images/        猫・カード・ボタンの画像
assets/audio/         効果音
assets/fonts/         表示フォント
css/                  配信表示・管理画面・演出
js/game/              カード判定・落下・音声・サイズ調整
js/shared/            Firebase接続・保存・設定検証・絵柄の抽選
js/display.js         配信表示
js/admin.js           管理画面
firestore.rules       管理者権限・画像保存制限
firestore.indexes.json 画像本文の不要な検索用インデックスを除外
tests/                設定・デッキ生成テスト
```

## Firebase / 公開

プロジェクトは `your-api-key-87e31`。管理者UIDは `js/shared/firebase.js` と `firestore.rules` に設定しています。メール・パスワード認証を使用します。設定は `memorySettings/current` の1件です。設定未保存時は標準の3種類・3ペアで動作します。

一般利用者は表示に必要な設定・画像の取得のみ可能です。保存、削除、画像一覧の取得は管理者だけが可能です。旧スロット・参加者データは削除せず、アクセスを閉じています。入れ子のカード設定は管理画面で保存前、配信表示で使用前に検証し、保存ルールで管理者権限と基本構成を制限します。

Firebase CLIで対象プロジェクトを明示してルールとインデックスを反映し、GitHub Pagesへ公開します。別プロジェクトのルールを上書きしないでください。

```sh
firebase deploy --only firestore --project your-api-key-87e31
node --test tests/model.test.mjs
```

変更前の素材・スロット実装はGit履歴に残っています。戻す場合はコードとFirebaseルールの両方の互換性を確認してください。
